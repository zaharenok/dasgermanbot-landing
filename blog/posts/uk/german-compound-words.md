Ви вивчаєте німецьку. Ви бачите слово, яке здається нескінченним:

Ваша реакція: «Як це взагалі може бути словом?!»

Ласкаво просимо в захоплюючий світ **німецьких складених слів (Komposita)** — де німці об'єднують слова як LEGO-блоки для створення всього: від простих термінів до монстрів, які неможливо вимовити!

**Хороша новина:** Німецькі складені слова слідують логічним паттернам. Як тільки ви зрозумієте систему, ви зможете навіть створювати власні слова!

## Що таке німецькі складені слова?

**Складені слова (Komposita)** — це слова, утворені шляхом об'єднання двох або більш існуючих слів для створення нового значення.

**В англійській:** Ми часто використовуємо пробіли або дефіси
- *ice cream* (два слова)
- *mother-in-law* (з дефісом)

**В німецькій:** Слова пишуться разом як одне
- *Eis + crem* = **Eiscream** (морозиво)
- *Schwieger + mutter* = **Schwiegermutter** (свекруха/теща)

**Чому німецька так робить?**
- Ясність: Одне слово = одна концепція
- Точність: Можна створювати точні значення
- Веселье: Німці люблять створювати нові слова!

## Як працюють німецькі складені слова

### Принцип будівельних блоків

Думайте про німецькі слова як про LEGO-блоки:

```
[Блок 1] + [Блок 2] + [Блок 3] = [Нове слово]
  Haus      + tür          + schlüssel  = Haustürschlüssel
  (будинок) (двері)      (ключ)        (ключ від дверей будинку)
```

### З'єднувальний елемент (-s- або -es-)

При об'єднанні слів німці часто додають з'єднувальний елемент:

**-s-** (найпоширеніший)
- *Arbeit + s + Buch* = **Arbeitsbuch** (підручник)
- *Liebe + s + Brief* = **Liebesbrief** (любовний лист)

**-es-** (після певних слів)
- *Geburt + es + Tag* = **Geburtstag** (день народження)
- *Antwort + es + Blatt* = **Antwortblatt** (аркуш відповідей)

**-n-** або **-en-** (множина)
- *Frau + en + Arzt* = **Frauenarzt** (гінеколог)
- *Kind + er + Garten* = **Kindergarten** (дитсадок)

**Без з'єднувального елемента**
- *Wohn +zimmer* = **Wohnzimmer** (вітальня)
- *Schlaf + zimmer* = **Schlafzimmer** (спальня)

## Правила складених слів

### Правило 1: Велика літера

Тільки **перша** слово пишеться з великої літери (як всі німецькі іменники):

✅ **H**aus + tÜR = **H**austür
✅ **B**uch + lADEN = **B**uchladen
✅ **S**onne + bRILLE = **S**onnenbrille

### Правило 2: Рід визначає останнє слово

Рід складного слова визначається **останнім** словом:

- **Der** Stuhl + **das** Zimmer = **Das** Schlafzimmer
- **Die** Tasche + **der** Boden = **Der** Handtascheboden
- **Die** Mutter + **der** Vater = **Die** Eltern

### Правило 3: Утворення множини

Додайте закінчення множини до **останнього** слова:

- **Der** Stuhl → **Die** Stühle → **Die** Schlafzimmerstühle
- **Das** Buch → **Die** Bücher → **Die** Schulbücher
- **Die** Tasche → **Die** Taschen → **Die** Handtaschen

## Створення власних складених слів

Німці постійно створюють нові складені слова. Ви теж можете!

## Стратегія вивчення

### Стратегія 1: Почніть з простого

Почніть з 2-словних складених, які використовуєте щодня:
- Haustür (вхідні двері)
- Tischlampe (настільна лампа)
- Handtasche (сумочка)

### Стратегія 2: Шукайте паттерни

Помітьте поширені типи складених:
- -zimmer (кімната): Wohnzimmer, Schlafzimmer, Esszimmer
- -maschine (машина): Waschmaschine, Spülmaschine, Nähmaschine
- -mittel (засіб): Haarwaschmittel, Geschirrspülmittel

### Стратегія 3: Розбивайте на частини

Коли бачите довге слово, розділіть його на частини:

**Kopfschmerztablette** = Kopf + Schmerz + Tablette
= голова + біль + таблетка
= таблетка від головного болю

### Стратегія 4: Використовуйте візуалізацію

Уявіть частини як образи:

```
[HOUSE] + [DOOR] + [KEY] = Haustürschlüssel
  🏠       🚪          🗝️
```

### Стратегія 5: Практикуйте з іграми

Спробуйте вгадати значення складених:
- Що таке *Hundehütte*? → Собача будка (hütte = будка)

## Поширені помилки

### Помилка 1: Неправильний рід

✅ Die Haustüren (множина останнього слова)

**Правило:** Додавайте закінчення множини тільки до останнього слова.

### Помилка 3: Відсутність з'єднувальних елементів

❌ Haus tür (відсутній -s-)
✅ Haustür (з -s-)

**Правило:** Перевірте, чи потрібен з'єднувальний елемент.

### Помилка 4: Надмірне складання

❌ Kaffeetassenzuckerdose (занадто складно)
✅ Kaffeetasse mit Zucker (простіше)

**Правило:** Використовуйте прийменники, коли складені стають занадто довгими.
