# Німецькі складені слова: Як будувати і розуміти довгі німецькі слова

Ти бачив їх. Ті жахливо довгі німецькі слова, які, здається, ніколи не закінчуються.

Слова на кшталт **Rindfleischetikettierungsüberwachungsaufgabenübertragungsgesetz** (63 літери!) виглядають неможливими для вимови, не кажучи вже про розуміння.

Але ось секрет: німецькі складені слова насправді неймовірно логічні. Як тільки ти зрозумієш систему, ти зможеш розібрати ЛЮБЕ німецьке слово, якої б довжини воно не було.

Готовий перемогти найдовші слова в німецькій мові?

## Що таке німецькі складені слова?

Німецькі складені слова (Komposita) — це слова, створені шляхом об'єднання двох або більше існуючих слів. На відміну від англійської, де ми використовуємо пробіли або дефіси, німецька просто з'єднує все в одне гігантське слово.

**Англійська:** "speed limit"
**Німецька:** "Geschwindigkeitsbegrenzung" (швидкість + обмеження + суфікс)

**Англійська:** "hospital"
**Німецька:** "Krankenhaus" (хворий + дім)

**Перевага:** Ти можеш створювати нові слова на ходу! Якщо німцям потрібно слово для чогось, вони просто будують його.

## Як працюють німецькі складені слова

### Основне правило

Візьми існуючі слова + з'єднай їх разом = нове слово!

**Приклади:**
- **Hand** (рука) + **Schuhe** (взуття) = **Handschuhe** (рукавички)
- **Schule** (школа) + **Bus** (автобус) = **Schulbus** (шкільний автобус)
- **Brot** (хліб) + **Tüte** (пакет) = **Brottüte** (хлібний пакет)

### З'єднувальні літери (Fugenlaute)

Іноді німецька додає додаткові літери між словами для кращого звучання:

- **-s-**: Liebe + Brief = **Liebesbrief** (любовний лист)
- **-e-**: Jahr + Zeit = **Jahreszeit** (час року)
- **-er-**: Stern + Uhr = **Sternenuhr** (зір'яні годинник)
- **-n-**: Auto + Fahrt = **Autofahrt** (поїздка на машині)

**Pro tip:** Не запам'ятовуй ці правила! Носії мови просто "відчувають", що звучить правильно. Ти також будеш з практикою.

## Категорії німецьких складених слів

### Іменник + Іменник (Найпоширеніше)

- **Haus** (дім) + **Tür** (двері) = **Haustür** (вхідні двері)
- **Tisch** (стіл) + **Bein** (нога) = **Tischbein** (ніжка стола)
- **Schlüssel** (ключ) + **Loch** (отвор) = **Schlüsselloch** (замкова щілина)

### Дієслово + Іменник

- **Schlafen** (спати) + **Zimmer** (кімната) = **Schlafzimmer** (спальня)
- **Waschen** (прати) + **Maschine** (машина) = **Waschmaschine** (пральна машина)
- **Sehen** (бачити) + **Hunde** (собаки) = **Sehhunde** (собаки-поводирі)

### Прикметник + Іменник

- **Grün** (зелений) + **Glas** (скло) = **Grünglas** (зелене скло)
- **Klein** (малий) + **Kind** (дитина) = **Kleinkind** (малюк)
- **Hoch** (високий) + **Haus** (дім) = **Hochhaus** (хмарочос)

### Число + Іменник

- **Drei** (три) + **Rad** (колесо) = **Dreirad** (трицикл)
- **Vier** (чотири) + **Eck** (кут) = **Viereck** (квадрат/прямокутник)
- **Zwei** (два) + **Kampf** (боротьба) = **Zweikampf** (дует)

## Чому німецька створює складені слова

### 1. Точність

Німецька любить бути конкретною. Замість "річ для нарізання хліба" вони просто кажуть **Brotmesser** (хлібний ніж).

### 2. Ефективність

Одне слово замість трьох:
- Англійська: "Drivers license"
- Німецька: **Führerschein** (очолюючий + щит/документ)

### 3. Логіка

Кожна частина слова має значення. Нічого не випадково!

## Як вимовляти довгі німецькі слова

### Крок 1: Розбий на частини

Знайди маленькі слова всередині великого:

**Donaudampfschifffahrtsgesellschaft**
= Donau + dampf + schiff + fahrt + gesellschaft

### Крок 2: Знайди головний іменник

Останнє слово завжди — головна категорія:
- **-gesellschaft** = компанія
- **-gesetz** = закон
- **-haus** = дім

### Крок 3: Додай наголос на кожну частину

Німці підкреслюють початок кожного "міні-слова":

DONAU-dampf-SCHIFF-fahrt-GESELLSCHAFT

### Крок 4: Практикуйся!

Почни повільно, затем прискорюйся. Твій язик звикне!

## Як створити свої німецькі складені слова

### Формула:

[Слово 1] + [Необов'язковий з'єднувач] + [Слово 2] = **Нове складене слово**

### Приклади:

1. **Твоє місто** + **Bahnhof** (вокзал)
   - Berlin + Bahnhof = **Berliner Bahnhof**
   - München + Bahnhof = **Münchner Bahnhof**

2. **Твій улюблений колір** + **Haus** (дім)
   - Blau (синій) + Haus = **Blauhaus** (синій дім)
   - Grün (зелений) + Haus = **Grünhaus** (теплиця)

3. **Будь-яка діяльність** + **-maschine** (машина)
   - Kaffee (кава) + maschine = **Kaffeemaschine** (кавоварка)
   - Geschirr (посуд) + maschine = **Geschirrspülmaschine** (посудомийна машина)

## Культурні нотатки

### Виняток "Camel Case"

Іноді німці використовують заголовні літери посередині складних слів:
- **KinderTagesstätte** (денний центр)
- **KraftFahrzeugBundesamt** (Федеральне автомобільне відомство)

Це трапляється з бюрократичними термінами і робить їх легшими для читання!

## Швидке вправа на практику

Розбий ці складені слова:

1. **Fahrrad** = Fahrrad (їхати/колесо) = Велосипед
2. **Schreibtisch** = Schreiben (писати) + Tisch (стіл) = Письмовий стіл
3. **Gartenhaus** = Garten (сад) + Haus (дім) = Садовий будиночок
4. **Kopfschmerzen** = Kopf (голова) + Schmerzen (біль) = Головний біль
5. **Wassermelone** = Wasser (вода) + Melone (диня) = Кавун

## Підсумок

Німецькі складені слова здаються лякаючими, але насправді вони:
- **Логічні:** Кожна частина має значення
- **Ефективні:** Одне слово замість багатьох
- **Творчі:** Ти можеш створювати свої!
- **Забавні:** Деякі поєднання просто смішні

**Ключ:** Шукай маленькі слова всередині великого слова. Розбий на частини, зрозумій кожну частину, і раптом 63-літерне слово стає цілком зрозумілим.

**Pro tip:** Почни з повсякденних складених на кшталт **Handschuhe** (рукавички) та **Schlafzimmer** (спальня). Як тільки зрозумієш патерн, довгі слова стануть легкими!

Пам'ятай: Німці не запам'ятовують ці довгі слова — вони будують їх інстинктивно. Ти також будеш!
